# Saturday 21 November 2026 — The World in One Day

[![rank](https://make.fun/badge/news-image-20261121/aam110/makefun-news-image-20261121-r3/rank.svg)](https://make.fun/bounty/news-image-20261121)

One image that sums up the world's news of **Saturday 21 November 2026** — a
front page drawn entirely in code: 35 verified stories across 9 regions, three
hero illustrations (the Gulf strikes, the burning cargo ship Sparta II off
Finland, COP31 in overtime), ten illustrated mediums, a world map with numbered
pins, a UTC timeline, a six-stat strip, and a DATE CHECK box naming the
well-known stories that belong to another day.

Every story here happened or was first reported on Saturday 21 November 2026,
told as the named outlets reported it. Text is set in real serif typefaces —
Liberation Serif and Noto Serif Display (OFL) — embedded as font outlines, so
every headline is a sharp, real serif face, not a hand-drawn imitation.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22 standard library only. The program draws one deterministic 1024×1024
PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (under 1 MiB, two runs byte-identical),
with no network access.
